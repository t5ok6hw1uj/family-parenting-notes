# 孩子总说自己学习不行？心理科医生教你用6招合理干预

> 更新时间：2026-09-16 (UTC+8)

**官方微信平台，点击上方欢迎订阅**

凌晨两点，林女士的手机突然震动起来——是儿子班主任的短信：“小宇今天又没交数学作业，他说反正写了也是错，不如不写。”她盯着屏幕，手指微微发抖。这已经是本月第七次了。

书房门缝透出微弱的光，她轻轻推开门，看到15岁的小宇蜷缩在椅子上。草稿纸散落一地，每张都写满凌乱的公式，又在最后一行被狠狠划破。桌角的台灯照着他发红的眼眶，那本曾被他当宝贝的《奥数精讲》，封面还印着小学五年级获得的市级竞赛奖章。

母亲试图拥抱儿子，却突然听到崩溃的大哭声：“我也不想这样！可我每次想努力，就听见脑子里有个声音说：“别试了，注定失败。”

**0****1****“习得性无助”的表现**

“**习得性无助**”这个概念来自于心理学家马丁·塞利格曼的动物实验，它指的是当动物长期经历“努力→失败→否定”的循环中，就会形成“做什么都没用”的核心信念。

在现代社会中，青少年在反复遭遇不可控的负面事情后，也会逐渐认为自己无力改变处境，于是开始放弃尝试。如果这种挫折出现的太频繁，严重时可能会演变成抑郁，甚至不愿意上学。

**！如果您的孩子出现以下表现，可能已陷入“习得性无助”：**

1. 常说“反正我也学不会”、“尝试有什么用”；

2. 对批评异常的敏感，对表扬却无动于衷；

3. 宁愿被骂“懒惰”，也不愿意努力后失败；

4. 不敢挑战困难，只会选择逃避。

**0****2****家长干预手册：六步打破“习得性无助”**

**第一步 改变反馈模式**** **
**（1）成功型反馈**

× “你真聪明。”

✓ “你用思维导图整理知识点，这种结构化思维对解决复杂问题很有帮助。”

**（2）失败型反馈**

× “你怎么这么蠢。”

✓ “这次没考好，是哪些具体环节卡住了？”“我们一起来找三种不同的解题方法怎么样？”

**（3）可能性质询**

× “为什么做不到？”

✓ “如果有个魔法按钮能改变一个条件，你会选择调整什么？”

**（4）隐喻疗法**

**尝试把困难比作“游戏关卡”**。

例如：当孩子面对数学的困难时，可以试着说：“这个数学单元就像新地图，需要集齐3把钥匙：公式理解、例题拆解、举一反三。”

**第二步 分解目标**
习得性无助的孩子总会把“失败=自我否定”，因此，我们需要帮助他们**建立自信心******。

将大目标分解成“跳一跳够得着”的小目标。例如：家长可以将大目标分解成可量化阶梯。假如孩子害怕当众演讲，可以选择先在镜子前练习→对家人演讲→3人小组发言→全班展示。

**第三步 用“过程反馈”替代“结果评价”**
家长可以试试这样说：“尽管这张试卷没有及格，但我发现你今天用了新的解题思路，真不错！”

**第四步 建立可视化系统**
家长可以邀请孩子一起制作“进步阶梯墙”，每完成一个目标就贴一颗小星星，并且定期回看，家长看到孩子进步时，应该及时表扬：“一个月前你还不会画辅助线，现在能解几何大题了。”

**第五步 提供情感支持**
当孩子说“我做不到”时，家长不要急着批判，先进行共情，（如“听起来你很难受”），再引导（“爸爸妈妈陪你一起想办法”），此时，可以讲诉自己如何从失败的经历中学习（如“妈妈以前也学不好英语，后来每天背5个单词，慢慢进步了”）。

**第六步 家校合作**
和教师建立紧密的联系，及时了解孩子在学校的表现，共同制定支持性计划。积极鼓励孩子参与集体性活动（如社团和运动会），帮助孩子重建信心。

习得性无助不是天生的，而是“习得”的，因此也可以**通过“再学习”而打破**。每一个“我做不到”的背后，都藏着一个渴望被看见、被支持的孩子。

当我们用耐心和智慧点亮他们的信心，习得性无助的阴霾终将散去。
