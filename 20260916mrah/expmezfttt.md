# 和孩子无法沟通？竟然用一个APPLE就能化解？！

> 更新时间：2026-09-16 (UTC+8)

孩子进入青春期

父母做好心理准备了吗？

独创**“苹果法则”**帮助你

提到青春期，大部分家长脑子里出现的都是孩子“叛逆”的形象，着装打扮稀奇古怪看不惯，狐朋狗友不求上进看不上，兴趣爱好根本不是一个次元，更是看不懂......孩子口中的父母，则是古板、专制、啰嗦，什么都不懂，什么都要管......影视作品里，当“更年期”碰上“青春期”，更是鸡飞狗跳，亲子冲突爆发像火星撞地球一样惨烈。好像青春期就是麻烦的代名词，青春期就是旷日持久的亲子大战。

好消息是，在过去三四十年中，心理学家开始系统研究青少年的思维、观点、行为，以及他们对生活的感受和对父母教育方式的回应。这些研究结果表明，许多关于青少年的普遍看法其实存在误区。

总结下来，好孩子并不会在青春期突然变坏，青春期确实面临很多挑战和困难，但问题行为并不像我们想象的那么普遍和持久；同伴压力也不会成为塑造青少年的唯一压倒性力量，**父母在孩子进入青春期以后，仍然可以且必须有所作为，孩子仍然非常需要父母，只不过需要的方式发生了变化。**

在门诊和生活中，我们常常看到“问题”青少年，他们的父母要么过度担忧，过度控制，总是把孩子当作长不大的小宝宝；或者完全忽视孩子的情绪和内心世界，很少陪伴，一旦出现问题要么高压管制，非打即骂，要么就是放任自流，听之任之。

因此，父母需要了解青少年的心理发展规律，不断学习和调整亲子沟通方法，才能真正胜任青少年家长这个角色。

我独创了一个好记的“苹果法则”（APPLE)，可以帮助您顺利进入青少年父母的角色！

✦  +

+

**Attitude 态度**

**1、保持积极，乐观，淡定！放轻松，再轻松点！**

现在的很多父母，太焦虑，神经绷得太紧了。孩子成绩波动几分，全家就要一级戒备，如临大敌。孩子要是偷偷打个游戏，就要上缴平板电脑甚至砸手机。如果孩子再有抑郁焦虑的表现，那父母更是无法承受。在门诊，常常可以看到痛哭流涕的妈妈，暴跳如雷的爸爸，比孩子更崩溃。

俗话说，如果你手里拿着锤子，看任何东西都是钉子，同理，如果你总抱着挑毛病的心态，那你的孩子肯定到处都有问题。没有完美的孩子，孩子们当然有缺点，父母难免会失望，但是请不要忘了，如何面对挫败，也是家长给孩子言传身教的重要一课。种瓜得瓜，种豆得豆。如果父母承受不了任何失望，你又怎么能埋怨孩子输不起呢？如果父母面对孩子任何问题都一惊一乍、反应过度，你又凭什么指责孩子心理太脆弱？

大量的研究证据发现，当遇到问题时，缩小困难面，放大积极面，更多强调孩子付出的努力和优势，一起展望那些有机会变得更好的地方，孩子往往会做得更好。

**2、保持开放的心态**

孩子进入青春期后，生理和心理都会发生巨变。当孩子开始质疑父母的权威，要求保护自己的隐私，渴望独立，这些都是正常的成长表现，不要认为孩子是针对你，故意疏远你。对孩子的种种变化，不要预设“应该”和“不应该”，不要总是随意去否定和批判。回忆一下自己在青少年时期，是多么讨厌父母的专横和武断。

反之，保持开放的心态，接受孩子的成长和变化。保持好奇，多听听孩子的感受和见解，你会发现，与进入青春期后的孩子进行平等的成人式对话很有趣，我常常通过和女儿的周末卧谈会，接触到最新的流行歌曲和小学生最爱的网络用语。用好奇而不是质问的态度去了解孩子的生活，你就会发现，大多数时候他们把自己照顾得挺好的。

✦  +

+

**Position 位置和姿态**

进入青春期以后，父母的位置要慢慢退到孩子身后。

青少年阶段就是从对父母言听计从的儿童，成长过渡到独立自主的大人。对青少年来说，父母的最佳角色应该是“高级合伙人”。虽然父母拥有更多的经验和知识技能，但是青少年最终还是要接管自己的人生，独当一面。我们需要循序渐进地逐步授予孩子自主权，比如买衣服，先允许他自己选择衣服款式，父母把控预算；然后他可以决定买衣服的花销，但在购买前要与父母核对；最后可以给他一笔零花钱，完全让他支配，自己买喜欢的衣服。

无论孩子走多远，当他需要父母的支持和安慰，转身奔向我们时，我们也要毫不犹豫地先给他们一个大大的拥抱。

✦  +

+

**Presence “在场”**

你可能常常听到“良好的亲子关系需要父母高质量陪伴”这句话，可是你理解什么是”高质量陪伴”吗？陪伴的核心是满足孩子的基本心理需求，让他们被看见、被理解、被肯定。然而如果父母一边陪孩子，同时刷手机看电视或者想工作，是没法真正“看见”孩子的，连孩子说什么可能都语焉不详，谈何揣摩孩子的言外之意，更不用说体察到孩子自己都不是很清楚的内心挣扎了。高质量的陪伴就是要求父母在亲子沟通中，对孩子全然关注，持续“在场”。

✦  +

+

**Less is better 做的少效果更好**

学会放手，是青少年父母的必修课。当父母知道孩子犯错，会有立刻去纠错的强烈冲动。但请记住，除非孩子的健康和人身安全受到威胁，否则请克制再克制，做得少效果会更好。我们要允许孩子犯错，同时要孩子自己承担后果。青少年需要从自己的错误中学习，学会为自己负责。

当你想要制止和纠正孩子时，先问自己：“如果我不做会发生什么？”例如孩子总是漏掉老师布置的作业，或者丢三落四，反复丢失书本，导致重要考试成绩不及格。你会怎么做呢？如果你每天替孩子去打听记录作业内容，整理书包，可以预见的是孩子类似的错还会一犯再犯，是你阻碍了孩子培养个人责任感。

✦  +

+

**Enable 赋能**

关注青少年情绪和行为问题背后的困难与缺乏的能力，帮助孩子提高这些能力而不是一味指责。

大多数青少年父母往往只关注孩子学业成绩和是否听话易于管理，却忽略了孩子各方面能力的培养。比如父母给孩子报补习班，一个不行就报两个三个，直到课余时间全被占满。然而不管多么高大上的补习班，主要还是知识的灌输，你是否关注过孩子真正的问题在哪里？也很少有家长去思考，补习班就算通过超前学、题海战术提高了几分成绩，但到底能不能提高孩子的学习能力？

很多时候，问题的本质往往是孩子能力不够。父母需要去认真观察孩子的注意力、时间感知和管理能力是否需要提高？有针对性地解决问题。

俗话说，一天一苹果，麻烦远离我！青少年父母们，不妨常常问问自己，和孩子的沟通中，自己做的还APPLE吗？
